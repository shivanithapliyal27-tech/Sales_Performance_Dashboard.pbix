# Sales Performance Dashboard

## Project Overview

This project presents an interactive Sales Performance Dashboard created using Power BI.

The dashboard analyzes sales performance by product category, region, and month.

## KPIs

- Total Sales
- Total Profit
- Total Quantity
- Profit Margin

## Dashboard Features

- Sales analysis by product category
- Sales analysis by region
- Monthly sales trend
- Profit by category
- Region filter
- Order date filter
- Interactive Power BI visuals

## Tools Used

- Power BI
- Sample Superstore Dataset
